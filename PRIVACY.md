# Privacy

This repository contains source code for a TypeScript package intended to configure browser
observability pipelines.

The repository itself is not intended to collect personal data simply by being cloned or reviewed.
However, software built from this repository may be configured to collect and export telemetry such
as page URLs, user actions, exceptions, network activity, session identifiers, traces, and logs to
Microsoft services or third-party backends.

If you use this software to collect telemetry from users or systems, you are responsible for:

- complying with applicable privacy, data protection, and notice requirements
- configuring only the telemetry you intend to collect
- choosing appropriate exporters and retention settings
- providing any required notices to end users

Microsoft's privacy statement is available at
[https://privacy.microsoft.com/privacystatement](https://privacy.microsoft.com/privacystatement).
