# PoC bundle size

Generated by `npm run size`. Every row is a real Vite production build of a real entry
point, minified and targeting `es2020`, which is the same pipeline the PoC itself builds
with (Vite 8, rolldown and the oxc minifier).

These numbers are only comparable to each other. They are **not** comparable to the size
shown on an npm package page, which measures a published tarball rather than the
tree-shaken, minified bytes that reach a browser.

Measured on 2026-09-16.

## Marginal cost of each addition

Each row is built on top of the bridge baseline (21.29 kB gzip), so the delta
is the cost of that package alone, including any dependency it pulls in that the baseline
did not already have.

Adding the baseline to the sum of the individual deltas gives 56.79 kB gzip,
against 41.50 kB measured for the combined bundle. The difference is shared
dependencies being counted once instead of once per package, which is why per-package
numbers must never simply be added up.
