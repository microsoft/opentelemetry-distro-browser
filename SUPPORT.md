# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/opentelemetry-distro-browser/issues)
to track bugs and feature requests. Search existing issues before filing a new one to avoid
duplicates.

For questions about Azure Application Insights, use the
[`azure-application-insights`](https://stackoverflow.com/questions/tagged/azure-application-insights)
tag on Stack Overflow. Use the question issue template for project-specific usage, configuration,
or behavior questions.

## Microsoft Support Policy

Support for this project is limited to the community and maintainer resources listed above. It is
not covered under a Microsoft standard support program or service.
